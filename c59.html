Chapter 6. Fasilitas Tambahan yang Ada di Program Ksystem.

  1. Fasilitas SMS: Program Ksystem dapat menerima sms atau mengirim sms (short message service) dengan menggunakan modem SMS (mis. Wavecom). Sms yang masuk dapat langsung mencari data dan mengirim jawaban via sms juga. (mis. Saldo barang tertentu masih berapa).

  2. Fasilitas Email: Program Ksystem dapat mengirim email secara otomatis ke alamat yang diinginkan.

  3. Fasilitas Absen Sidik Jari: Program Ksystem dapat memastikan bahwa karyawan yang masuk tidak menitipkan absennya ke orang lain karena dapat diverifikasi dengan sidik jari. Fasilitas sidik jari ini juga dapat dijalankan di semua cabang dan informasi sidik jari akan disimpan di server pusat.

  4. Fasilitas Kirim pesan ke user lain: Program Ksystem memungkinkan satu user untuk mengirim pesan ke user lain. User yang dituju akan tahu ada pesan yang masuk dengan adanya tanda MSG di tampilan layarnya.

  5. Fasilitas Ticker: Program Ksystem dapat memberikan pesan yang muncul di baris bawah monitor ke pada semua user.

  6. Fasilitas Pengaturan User: Program Ksystem membatasi dengan ketat

    1. wewenang setiap user untuk mengakses screen yang diijinkan.

    2. Nomor rekening buku besar yang boleh diakses (Chart of Accounts).

    3. Cabang dan divisi yang boleh diakses.

    4. Field field tertentu yang harus dilindungi (mis. Harga Pokok Barang).

  7. Fasilitas Online Via Speedy atau VPN: Karena program Ksystem sangat hemat memori dan membutuhkan bandwidth yang sangat kecil, program Ksystem dapat dijalankan secara ringan hingga ribuan komputer secara bersamaan melalui jaringan speedy atau VPN IP (Virtual Private Network Internet Protocol).

  8. Pemilik atau manager perusahaan dapat mengakses data di komputer server secara online realtime dengan menggunakan iPad atau Nokia Smartphones seperti N97 atau N8.

  9. Fasilitas Transaksi Lintas Cabang: Program Akuntansi Ksystem mempunyai fasilitas untuk melakukan transaksi antar cabang yang elegan seperti pembayaran hutang cabang di pusat, pengiriman uang antar cabang, pengiriman barang antar cabang, biaya yang dibebankan ke pusat. Transaksi antar cabang ini cukup merepotkan bagi perusahaan yang biasa mempunyai program yang terpisah pisah di setiap cabang dan sekarang ingin mengintegrasikan semua program menjadi program akuntansi yang online real-time. Program Akuntansi Ksystem akan membantu perusahaan yang ingin terintegrasi secara online real-time untuk semua cabang yang tersebar di banyak tempat secara mudah dan cepat.

  10. Fasilitas Approval Online: Program Akuntansi Ksystem telah mengembangkan fasilitas approval secara online. Misalnya setiap cabang mempunyai wewenang untuk menyetujui besaran biaya atau diskon untuk penjualan secara berjenjang sesuai dengan nilai yang ditetapkan. Orang orang yang menyetujui dapat tersebar di cabang atau di wilayah atau di pusat. Setiap kali ada transaksi yang perlu diapprove oleh orang yang terkait, pesan tertentu akan muncul di layar orang yang harus mengapprove secara realtime dan orang tersebut dapat langsung mengambil tindakan begitu transaksi sudah dimasukkan ke proses approval.

  11. Fasilitas Struktur Data Terbuka: Program Ksystem menyediakan informasi mengenai file dan index yang tersedia via scr917. Semua file dan inforamsi yang ada di dalam file dapat dipelajari oleh perusahaan dan tidak ada yang ditutup-tutupi.

  12. Fasilitas Program Terbuka: Source program akuntansi Ksystem sepenuhnya terbuka dan dapat dipelajari oleh perusahaan. Semua program berada di dalam direktori prg. Mis. Source untuk scr201 berada di prg/scr201.
