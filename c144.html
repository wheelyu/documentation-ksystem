Chapter 14. Cara install Scanner Sidik Jari Futronic FS80 atau FS88

Program Ksystem menyediakan fasilitas scanner sidik jari yang canggih. Semua data sidik jari baik yang di lokasi pusat maupun yang ada di cabang cabang akan disimpan secara otomatis di komputer server. Dengan cara ini, bila ada kerusakan alat sidik jari, alat tinggal diganti saja tanpa harus mendaftarkan ulang orang yang ada di cabang tsb. Juga bila ada karyawan yang harus berkunjung dari satu cabang ke cabang lain, karyawan tsb. dapat dengan mudah absen di cabang yang dikunjungi tanpa harus mendaftar lagi atau membawa kartu tambahan lain.

Program untuk membaca sidik jari ada di dalam file ksfinger.tgz yang tersedia pada saat download program ksystem.sh atau kslinux.tgz. Cara Memasang ksfinger adalah sbb:

Ksfinger diinstall di setiap komputer yang ada scanner sidik jarinya. Program ksfinger menggunakan port 8080, kalau ada masalah dengan pembatasan port, pembatasan (firewall) dinonaktifkan dulu. Ksfinger hanya berjalan di komputer Linux.

  1. Login sebagai root

  2. cp /home/ksystem/ksfinger.tgz .

  3. tar xvfz ksfinger.tgz

Cara menjalankan secara manual

  1. Login sebagai root

  2. Ketik ./ksfinger

Cara menjalankan secara otomatis

  1. login sebagai root 

  2. 	vi /etc/rc.local
	Di bawah baris terakhir tambahkan sbb:
	cd /root
	./ksfinger &

  3. /etc/rc.local ini akan dijalankan otomatis pada saat komputer hidup.

Untuk mencoba sidik jari, pasang scanner sidik jari di komputer dan jalankan run -sj atau ksrun -sj keumudian login sebagai root. Secara otomatis anda akan dibawa ke scr933 untuk pendaftaran sidik jari. Selamat mencoba.
