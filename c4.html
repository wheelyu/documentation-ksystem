Chapter 1. Install Program K-System dan Bahasa K-System 

   Anda bisa download Program K-System dan Bahasa K-System di ksystem.co di pilihan "download":
  	1. Program K-System  terdiri dari 1 file yaitu PrgWeb+th+bl+tgl.taz (misal:PrgWeb20161031.taz)
  	2. Bahasa K-System terdiri dari 2 file yaitu ksystem+th+bl+tgl.wt   (misal:ksystem161031.wt) dan 
                                          	     parsegen+th+bl+tgl.tgz (misal:parsegen161031.tgz).
	

  Cara install Bahasa K-System:   
	- sudo  killall -9 ksystem.wt (non aktifkan ksystem.wt yang masih aktif)
	- cp  Downloads/ksystem161031.wt ksystem.wt
	- tar  xvfmz Downloads/parsegen161031.tgz

  Cara install K-Program:   
        1. Membuat direktori "strlama" apabila anda belum punya direktori ini dengan cara:
	       mkdir   strlama   (tekan enter)


	2. Menyimpan struktur yang lama ke direktori strlama dengan cara:
	       cp  *.str  strlama  (tekan enter)


	Apabila install K-Program ini adalah yang pertama bagi anda dan anda blm memiliki database 
	maka selanjutnya langsung jalankan no.5. 
	sedangkan no.3 dan no.4 khusus bagi anda yang sudah pernah menginstall K-program dan mengisi 
	datanya.


	3. Menyimpan semua data anda untuk jaga jaga apabila anda gagal melakukan perubahan program. 
	  data yang ada simpan ini bisa dikembalikan lagi. Cara menyimpan data:
	       simdatsql  NamaDataBase  TglHariIni  (tekan enter)

	       (misal: simdatsql  ksystem  161031   ---> database anda ksystem)
	       (misal: simdatsql  kscoba   161031   ---> database anda kscoba)
	       dll


	4. Mengubah data anda dengan struktur yang baru dengan cara:
	        dtubhver  -sql  (tekan enter)
		mysql -uroot -proot NamaDataBase < ubhsql.txt  (tekan enter)

		Misal:
		mysql -uroot -proot ksystem < ubhsql.txt  	(tekan enter)
		mysql -uroot -proot kscoba < ubhsql.txt  	(tekan enter)
		dll


	5. Membuat frm dengan struktur baru, dengan cara:
		kspar  -n  all   (tekan enter)
	        ksgen  		    (tekan enter)
	   Untuk anda yang sudah memiliki program tambahan misalnya dengan nomer pelanggan 9001
	   maka jalankan perintah dibawah ini:
		kspar  -n  -x9001  	(tekan enter)
		ksgen  -x9001		(tekan enter)


	6. Mengaktifkan K-Program di browser dengan cara:
           sudo  ./runwt    (tekan enter)
