Chapter 9. Harddisk, Memori dan CPU (Central Processing Unit)

Harddisk adalah tempat penyimpanan program dan data. Data yang sudah disimpan di harddisk tetap tersedia pada saat komputer sudah dimatikan.

Memori atau biasa disebut RAM (random access memory) adalah tempat menjalankan program komputer. Kecepatan RAM sekitar 100 ribu kali kecepatan harddisk. Data yang ada di memori akan hilang pada saat komputer mati.

CPU atau central processing unit adalah "otak" dari komputer yang menjalankan program. Program pertama dipindahkan dari harddisk ke memori dan kemudian dijalankan di memori. Walaupun program berjalan di memori, program akan menambah, mengubah atau menghapus rekord database yang ada di harddisk.
