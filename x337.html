16.3. Mengenal Perintah DEFAULT

Perintah DEFAULT mengeset informasi awal dari field, bisa dilakukan pada saat menambah, ubah atau pada saat pencarian (QUERY). Perintah INIT adalah sama dengan INIT_ADD yaitu pemberian nilai pada saat kita menekan tombol 't'. Tambahkan program di bawah ini di atas perintah END_SCREEN. Kemudian lakukan kspar prt9000/sct271 lagi. INIT_UPDATE untuk pada saat kita mengubah data dengan menekan tombol 'u' sedang DFALT_SCAN akan memberikan kita pilihan yang dapat dipilih untuk field tertentu. Cobalah ketik program di bawah ini di atas END_SCREEN. 

/*---------------------------DEFAULT MASTER----------------------------*/
DEFAULTS(master)
  bkksts     INIT             	OPEN 
  bkktype2   INIT_QUERY       	KK
  bkktype DFALT_SCAN  PU "Keluar Kas Untuk Biaya Umum"
				  HL "Membayar Hutang Lain"
				  PL "Keluar Kas Untuk Piutang Lain"
				  PP "Keluar Kas Untuk Piutang Pegawai"
				  HC "Membayar Hutang Komisi"

  bkkstsexp  	DFALT_SCAN      BI  "Untuk Biaya Umum"
				BAT "Untuk Biaya Aktiva Tetap"
				BPO "Untuk Biaya Penggantian Obat"

  bkkkb         DFALT_SCAN      KS  "Keluar KAS"
			  	BK  "Keluar BANK"

  bkktgl     	INIT             	{g_tgltrn}

  bkktype2   	INIT             	KK
  bkkcrtusr  	INIT	      		{g_usrkode}
  bkkupdusr  	INIT_UPDATE      	{g_usrno}

Sesudah berhasil kspar prt9000/sct27, jalankan ksrun -x9000 lagi, masuk ke sct271 dan coba tekan tombol 't' untuk menambah rekord. Field akan berada di field No.Bukti. Tekan enter untuk memindahkan field ke field Jenis. Kita lihat field ini secara otomatis sudah terisi dengan PU. Untuk mengubah nilai default ini, tekan spasi, maka di layar akan muncul pilihan sbb:

Pelajari perintah DEFAULT ini dengan membaca daftar perintah di bab awal.
