Chapter 4. File-File Penting Yang Ada di K-Program.

    Daftar file yang ada di K-Program bisa anda dilihat di file posting.h, dimana ada sekitar 115 s/d 120 file. 
    Tetapi dari 120 file tersebut, ada beberapa file penting yang harus anda ingat dan pahami fungsinya. 
    
    File File penting tersebut adalah:
       - File Kode
       	  1. bbm	: File buku besar master. misal 100.01 (kas)
	  2. bbg	: File gabungan nomer buku besar dengan grup misal: 100.0101 adalah kas kecil
	  								    100.0102 adalah kas kantor
	  3. bbc	: File neraca dan rugi laba, yang menyimpan informasi,nomer file bbg(misal 100.0101),tahun bulan,Cabang,Divisi,
	  		  Saldo Awal, Mutasi Debet, Mutasi Kredit, Saldo Akhir.
    	  4. cmp 	: File Pelanggan, Suplier, Hutang lain dan piutang lain.
    	  5. brg	: File Barang yang menyimpan semua informasi tentang barang Misal: Kode, Nama barang, satuan, kategori dll
	  6. brd	: File saldo FIFO/LIFO barang
	  7. tbl      	: File tabel. File ini menyimpan data yang sifatnya informasi berdasarkan kelompok tertentu. misal:		
	  		  Data Kategori Barang, Satuan barang, Lokasi barang, Ukuran barang, Bidang Usaha Pelanggan, Bidang Usaha
			  Suplier, Agama, Gol Darah Karyawan, Jabatan Karyawan dll
	  8. tbd	: File yang menyimpan perincian informasi dari file tbl. misal data tbl untuk Satuan Barang, data tbd adalah 
	                  pcs, dozen, koli, kg, buah, pasang dll.
	  9. cab	: File yang menyimpan informasi cabang.
	  10. psm,psi   : File yang menyimpan informasi seseorang. Misalnya: Karyawan, Kolektor, Pasien, Kasir dll


       - File Transaksi
          1. bkm,bkd,tcm     : File yang menyimpan data transaksi terima kas/bank dan transaksi keluar kas/bank.
	  2. ppm,ppd,tcm     : File yang menyimpan transaksi penjualan baik tunai / kredit
	  3. pmb,ppd,tcm     : File yang menyimpan transaksi pembelian baik tunai / kredit
	  4. mts,mtd,tlm,tld : File ini bisa dipakai untuk transaksi lainnya. misalnya: Pesanan barang, Koreksi Barang,
	                       Mutasi Barang dll
