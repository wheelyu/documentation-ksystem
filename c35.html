Chapter 4. Struktur Direktori Ksystem

Pengaturan direktori atau folder dalam Ksystem.

  1. Screen standar ada di prg. Kalau kita di windows itu berarti ada di c:\ksystem\prg dan kalau kita di Linux itu ada di /home/ksystem/prg. Mis. prg/scr201.

  2. Screen khusus perusahaan tertentu ada di prt{Kode_perusahaan} Jadi kalau kode perusahaan adalah 0567 (selalu 4 digit), maka program tambahan (penyesuaian) untuk perusahaan ada di prt0567. Mis. prt0567/sct201. Kalau di Windows berarti di c:\ksystem\prt0567\sct201 sedang di Linux akan berada di /home/ksystem/prt0567/sct201. Program single user dapat juga diubah tanpa batasan apapun. Nomor pelanggan untuk program single user harus antara 9000 s/d 9999.

  3. Hasil kspar dari screen baku akan berada di frm. Mis. kspar prg/scr201 akan membentuk file frm/scr201

  4. Hasil kspar dari screen tambahan akan berada di frm{kode_perusahaan}. Mis. kspar prt0567/sct201 akan membentuk file frm0567/sct201.frm

  5. Untuk setiap screen di prg mis. scr201, maka ada file key/scr201.key yang menjaga agar prg/scr201 tidak bisa diubah.
