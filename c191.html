7.1. Program 1, SCREEN, IMAGE dan FIELD

	Dalam Program 1 kita akan belajar membuat program untuk pelanggan "UD.MAJU JAYA" 
	dengan nomer pelanggan Ksystem 9001. 
	Program 1 ini akan berisi:
	- Membuat direktori prt9001 	
	- Membuat Program Menu di prt9001 dengan nomer sct2900 dan judul "t.BelajarProgram"
	  vi prt9001/sct2900

	  SCREEN 2900 MENU_TYPE t.BelajarProgram
	  END_SCREEN

	- Menjalankan perintah kspar yang berfungsi mengubah program yang kita buat 
	  misal prt9001/sct2900 menjadi program yang bisa dibaca oleh komputer yang di 
	  simpan di frm9001/sct2900.frm. Jadi setiap kali kita mengubah program, maka harus
	  menjalankan perintah kspar ini. Supaya perubahan terbaru bisa dibaca di komputer.
	- Menjalankan perintah ksgen -x9001. 
	  ksgen ini berfungsi untuk menggabungkan semua scr*.frm yang ada di direktori frm dan 
	  semua sct*.frm yang ada di direktori frm9001 supaya bisa menjadi program yang bisa 
	  dijalankan di browser. Perintah ksgen atau ksgen -x???? ini hanya dijalankan sekali saja, 
	  saat ada tambahan sct baru. jika hanya mengubah sct yang sudah ada tidak perlu menjalankan 
	  perintah ksgen.
	- Menjalankan program ksystem di browser. Dan sekarang perhatikan sudah ada menu 2900 dengan 
	  judul "??t.BelajarProgram??"

	  1. Sekarang kita akan membuat file sct2901 di prt9001
	     dengean perintah vi prt9001/sct2901
	     Masukkan sbb:

	  SCREEN 2901 QUERY_TYPE Program 1
	  SCR_FILE bkm

	  IMAGE(master)
	  /-----------------------------------------------------\
	  |                                                     |
	  |  No.Bukti: ____________________                     |
	  |  Total   : __________.__                            |
	  |                                                     |
	  /-----------------------------------------------------\

	  FIELD(master)
	    bkmnobuk	ALLCAPS		NONE	1
	    bkmtotal	NONE		NONE	2

	  END_SCREEN


	  2. kspar prt9001/sct2901
	  	Perintah ini akan membuat frm9001/sct2901.frm

	  3. ksgen -x9001
	  	Perintah ini membuat scrdef9001.var yang berisi layar baru 2901
